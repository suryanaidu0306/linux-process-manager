# Linux Process Manager

## Description

A Bash script to monitor and search Linux processes.

## Features

- Shows current date
- Shows current user
- Shows hostname
- Lists top CPU-consuming processes
- Lists top memory-consuming processes
- Searches for a specific process

## Commands Used

- ps
- grep
- head
- date
- whoami
- hostname

## Run

```bash
chmod +x process_manager.sh
./process_manager.sh
```
